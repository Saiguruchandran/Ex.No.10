## Procedure:
1.	Introduction to Prompt Patterns: Begin by understanding the following prompt patterns:
○	Query Decomposition: Breaking down complex queries into smaller, actionable parts.
○	Decision Making: Asking the model to choose between options or directions.
○	Answer Engineering: Refining outputs by giving detailed instructions on how to structure or format the answer.
○	Fact Check List: Ensuring the content is factually accurate, especially for reports or case studies.
○	Tail Generation: Extending the content logically to create depth in storytelling or analysis.
○	Menu Actions: Presenting multiple action choices and guiding the AI to select one.
○	Semantic Filter: Applying filters to control the tone, style, and accuracy of the content.
2.	Choosing the Content Type: Decide on the type of content you want to create. This could be:
○	Reports (e.g., industry analysis, sustainability reports, etc.)
○	Case Studies (e.g., business solutions, technological innovations)

○	Creative Content (e.g., comic book story, short stories, video scripts)
3.	For example, you could choose a business report on market trends, a case study on a successful startup, or even a story-based prompt like creating a fictional world for a comic.
4.	Creating the Prompts:
○	Start with simple prompts to generate initial content.
○	Gradually refine the prompts, moving toward more complex techniques like decision-making (asking the model to pick one of several options), tail generation (extending the narrative), and semantic filtering (adjusting style or tone).
5.	Generating and Refining Outputs: Use the model to generate initial drafts, and then refine the outputs using iterative adjustments:
○	For a report, prompt the model with basic data, then ask for a deeper analysis and insights.
○	For creative content, refine the initial story idea with specific details on characters, settings, or actions.
6.	Review and Evaluation: After generating content, evaluate the outputs for:
○	Coherence: Is the generated content logical and structured?
○	Creativity/Originality: Is the content engaging and fresh?
○	Accuracy: Is the content factually accurate (for reports and case studies)?
○	Tone and Style: Does the content match the intended tone (formal, creative, educational)?

# Prompting Techniques Used

# 1. Query Decomposition Prompting

## Explanation

Query decomposition breaks complex tasks into smaller sub-problems. This helps AI generate more organized and logically structured responses.

## Features
- Improves organization
- Creates step-by-step outputs
- Reduces ambiguity
- Enhances readability
- Helps handle complex tasks

## Example Prompt

```text
First explain climate change causes, then explain its effects, and finally suggest preventive measures.
```

## AI-Generated Response

1. Causes of climate change include greenhouse gas emissions and deforestation.  
2. Effects include rising temperatures, floods, and extreme weather conditions.  
3. Preventive measures include renewable energy usage and reducing carbon emissions.  

## Analysis

- Improved structure
- Better content organization
- Logical information flow
- Easier understanding

---

# 2. Decision-Making Prompting

## Explanation

Decision-making prompts guide AI systems to compare alternatives, analyze advantages and disadvantages, and recommend the best solution.

## Features
- Supports analytical thinking
- Produces comparison-based outputs
- Useful for evaluations
- Helps generate recommendations
- Improves reasoning quality

## Example Prompt

```text
Compare solar energy and wind energy based on cost, efficiency, and environmental impact. Recommend the better option for rural areas.
```

## AI-Generated Response

| Factor | Solar Energy | Wind Energy |
|---|---|---|
| Cost | Moderate | High |
| Efficiency | High in sunny regions | Depends on wind conditions |
| Environmental Impact | Low | Low |

### Recommendation

Solar energy is more suitable for rural areas because it is easier to install and maintain.

## Analysis

- Generates analytical responses
- Produces clear comparisons
- Supports decision-making processes

---

# 3. Semantic Filtering Prompting

## Explanation

Semantic filtering prompts instruct AI to focus only on relevant information while excluding unnecessary details.

## Features
- Produces focused outputs
- Reduces irrelevant content
- Improves response clarity
- Enhances topic relevance
- Useful for technical summaries

## Example Prompt

```text
Explain Artificial Intelligence focusing only on healthcare applications.
```

## AI-Generated Response

Artificial Intelligence in healthcare is used for:
- Disease diagnosis
- Medical imaging analysis
- Patient monitoring
- Drug discovery
- Robotic surgeries

## Analysis

- Improved relevance
- Reduced unnecessary information
- More focused responses

---

# 4. Role-Based Prompting

## Explanation

Role-based prompting asks AI to respond from a specific professional or contextual perspective.

## Features
- Generates audience-specific explanations
- Improves realism
- Enhances contextual understanding
- Useful for simulations and teaching
- Produces practical explanations

## Example Prompt

```text
Act as a cybersecurity expert and explain phishing attacks to college students.
```

## AI-Generated Response

Phishing attacks are cyber scams where attackers trick users into revealing sensitive information such as passwords or banking details using fake emails or websites.

## Analysis

- Audience-focused explanation
- Improved contextual quality
- More realistic responses

---

# 5. Chain-of-Thought Prompting

## Explanation

Chain-of-thought prompting encourages AI to explain reasoning step by step before arriving at the final answer.

## Features
- Produces detailed reasoning
- Encourages logical explanations
- Useful for educational tasks
- Improves analytical depth
- Enhances problem-solving capability

## Example Prompt

```text
Explain how machine learning works step by step.
```

## AI-Generated Response

1. Data is collected from various sources.  
2. The data is cleaned and prepared.  
3. Algorithms analyze patterns in the data.  
4. The model learns from examples.  
5. Predictions are generated based on learned patterns.  

## Analysis

- Produces detailed explanations
- Improves reasoning clarity
- Useful for teaching complex concepts
